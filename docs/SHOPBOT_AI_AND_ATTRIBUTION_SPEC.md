# 3XUI-SHOPBOT: Спецификация аудита, AI-онбординга и сквозной атрибуции

## 1. Контекст и бизнес-логика сервиса
- **Основной шоп-бот:** Автоматизирует выдачу подписок, взаимодействует с 3x-ui API (VLESS Reality / XHTTP), генерирует тестовые ключи на 3 дня (`trial`), принимает платежи и управляет профилем пользователя.
- **Поддержка клиентов:** Связка с пользователем при возникновении технических неполадок и сбоев подключения.
- **Новая задача:** 
  1. Полный аудит кодовой базы, исправление багов в шаблонах сообщений, HTML/Markdown-разметке и инлайн-клавиатурах.
  2. Перехват контекстных диплинков (`/start <payload>`), сохранение источника лида.
  3. Подключение ИИ-модели (OpenRouter API) для динамической генерации персонализированных адаптивных приветствий и консультаций по болям входящего пользователя (YouTube, Discord, блокировки ТСПУ, настройка клиентов).

## 2. Карта входящих Deep-Link меток (Attribution Matrix)

| Payload (`start=...`) | Источник / Боль | Фокус ИИ-онбординга | Авто-оффер |
|---|---|---|---|
| `ref_yt` | Замедление / лаги YouTube, 4K Smart TV | Разъяснение обхода троттлинга ТСПУ, принудительный VLESS | Тест 3 дня + инструкция под роутер/ТВ/ПК |
| `ref_ds` | Блокировка Discord, войс, UDP, пинг | Оптимизация UDP/джиттера, стабильный голос | Тест 3 дня + быстрый конфиг под ПК/мобилку |
| `ref_rkn` | Падение WireGuard, OpenVPN, бан IP | Бессигнатурный VLESS Reality, маскировка под TLS | Тест 3 дня с акцентом на стабильность |
| `ref_mob` | iOS / Android клиенты, батарея | Подбор клиента (v2rayNG, Streisand, FoXray, Sing-box) | Тест 3 дня + импорт по 1 клику / QR-код |
| `ub_bio` / `ref_promo`| Органический переход из био аккаунта | Универсальное премиальное знакомство с сервисом | Стандартный тест на 3 дня |

## 3. Архитектура интеграции ИИ (OpenRouter)

### 3.1. Слой генерации адаптивных приветствий (`app/services/ai_onboarding.py`)
- При переходе по диплинку бот не должен слать шаблонный сухой текст. 
- На основе переданного `payload` и имени пользователя формируется запрос к легковесной модели OpenRouter (например, `meta-llama/llama-3.3-70b-instruct` или `google/gemini-2.5-flash`):
  - **Роль модели:** Профессиональный инженер техподдержки и консультант NeoVPN.
  - **Задача:** Кратко (до 450 символов), доброжелательно и убедительно закрыть страх клиента по его конкретной проблеме, объяснить преимущество VLESS Reality и подтолкнуть нажать кнопку выдачи 3-дневного ключа.

### 3.2. Автоответчик первого контакта:
- Если после `/start` пользователь в течение первых 15 минут задает сопутствующий вопрос («а как настроить на айфон?», «а дискорд точно заработает?»), ИИ-ассистент перехватывает сообщение, формирует четкую инструкцию со ссылкой на готовый гайд и предлагает помощь живого саппорта, если проблема не решена.

## 4. Схема данных и миграции (SQLAlchemy)

### 4.1. Доработки таблицы пользователей (`users`):
- `acquisition_source VARCHAR(64) NULL` — зафиксированный реферальный тег (например, `ref_yt`).
- `demand_segment VARCHAR(32) DEFAULT 'general'` — сегмент интереса пользователя.
- `trial_granted BOOLEAN DEFAULT FALSE` — флаг выдачи бесплатного 3-дневного доступа.
- `trial_granted_at TIMESTAMP WITH TIME ZONE NULL` — дата активации триала.
- `converted_to_paid BOOLEAN DEFAULT FALSE` — факт первой оплаты подписки.

### 4.2. Таблица аналитики источников (`traffic_sources_stat`):
- `source_tag VARCHAR(64) PRIMARY KEY`
- `clicks_count INTEGER DEFAULT 0`
- `trials_count INTEGER DEFAULT 0`
- `sales_count INTEGER DEFAULT 0`
- `total_income NUMERIC(10, 2) DEFAULT 0.0`
